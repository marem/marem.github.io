Executive briefing task · ≤100 words
Recommend one proposal to the Financial Director.
  1. Name the selected proposal.
  2. Use at least two quantified pieces of Excel evidence.
  3. State one explicit commercial trade-off.
  4. Name one unverified operational assumption that must be confirmed before contract signature.

There is no single acceptable recommendation if the reasoning is coherent, quantified and appropriately qualified.
